# Angular Base Microservice

This package contains the Angular frontend.

## Prerequisites

- Node.js 20+ (recommended)
- npm 10+ (recommended)

## Install Dependencies

```bash
npm install
```

Run this command from `angular_base`.

## Run in Development Mode

```bash
npm start
```

This runs `ng serve` and starts the app at:
- http://localhost:4200

## Build for Production

```bash
npm run build
```

## Watch Build (Development)

```bash
npm run watch
```

## Quick Command Summary

- `npm start`: start dev server
- `npm run build`: production build
- `npm run watch`: build in watch mode
