🚀 Quick Start

1. Start Full Stack

cd c:\local_store\files\my_workspace\msaas docker-compose up -d

2. Run Tests

# Unit tests only (fast) mvn clean test # All tests (unit + integration) mvn clean verify # With coverage report mvn clean verify jacoco:report # View coverage start spring_base/auth-service/target/site/jacoco/index.html

3. Access Services

API Gateway: http://localhost:8080 Auth Service: http://localhost:8081 Organization: http://localhost:8082 Billing: http://localhost:8083 Notifications: http://localhost:8084
